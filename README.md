# Оценка вина

Приложение отбирает вина для подборки по их характеристикам

Проверено на Python 3.12.14, библиотеки указаны в requirements.txt

## Запуск

Открой терминал в папке wine_app и выполни:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

## Вкладки

- Одно вино: характеристики, вероятность и решение
- Модельные метрики: порог, матрица ошибок, precision, recall, F1, ROC и PR
- Загрузить CSV: прогнозы для таблицы и скачивание результата
- Что выучила модель: коэффициенты после масштабирования

В CSV нужны 12 признаков с теми же названиями, что в исходных данных, без target, is_red принимает 0 или 1

## Модель

StandardScaler и LogisticRegression без весов классов, порог выбран на валидации для максимального precision при recall не ниже 0.7

Модель, порог и test.csv сохраняются из ноутбука, приложение модель не обучает

## Кэширование

st.cache_resource хранит один объект модели, st.cache_data хранит таблицы и вероятности и возвращает копии данных

При изменении порога вероятности остаются прежними, без декоратора joblib.load читал бы модель заново при каждом действии
